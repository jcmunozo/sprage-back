How to Use the /api/vocabulary/import Endpoint

This document explains how to use the POST /api/vocabulary/import endpoint to populate your MongoDB database with data from the 'unified_data.json' file.

Purpose:
--------
The '/api/vocabulary/import' endpoint is designed to automate the process of importing vocabulary, idiom, and grammar data into your database. It reads the 'unified_data.json' file located in the root of your project directory, processes its content, and then either creates new entries or updates existing ones based on the 'id' field.

Endpoint Details:
-----------------
-   Method: POST
-   URL: http://localhost:5000/api/vocabulary/import (assuming your server runs on port 5000)
-   Request Body: NONE. This endpoint does NOT require a request body. It directly reads the 'unified_data.json' file from the server's filesystem.
-   Response:
    -   Success (200 OK): Returns a JSON object indicating the success of the import, including the number of new items imported and existing items updated.
        Example: {"message":"Vocabulary import complete","importedCount":X,"updatedCount":Y}
    -   Error (500 Internal Server Error): Returns a JSON object with an error message if something goes wrong during the file reading, parsing, or database operations.

Prerequisites :
--------------
1.  **Running Server**: Ensure your Node.js backend server is running. You can start it by navigating to your project directory in the terminal and running:
    ```bash
    npm start
 |  ```
2.  **unified_data.json**: Make sure the 'unified_data.json' file is present in the root of your project directory and contains the data you wish to import in the expected JSON array format. This file should be structured correctly, with each object having the 'id', 'type', 'language', 'front', 'back', 'example', 'tags', 'category', and 'difficulty' fields (missing fields will be defaulted as per the schema).

How to Trigger the Import:
--------------------------

You can trigger this endpoint using various HTTP clients.

**1. Using cURL (Command Line):**
Open your terminal or command prompt and execute the following command:
```bash
curl -X POST http://localhost:5000/api/vocabulary/import
```

**2. Using Postman, Insomnia, or similar API Clients:**
1.  Open your preferred API client.
2.  Set the HTTP Method to `POST`.
3.  Enter the Request URL: `http://localhost:5000/api/vocabulary/import`.
4.  Ensure that the "Body" section is set to `none` or `No Body`.
5.  Click the "Send" button.

**3. Using a Web Browser's Developer Console (for quick testing - not recommended for production):**
You can execute a simple fetch request from your browser's developer console (F12):
```javascript
fetch('http://localhost:5000/api/vocabulary/import', {
  method: 'POST',
})
.then(response => response.json())
.then(data => console.log(data))
.catch(error => console.error('Error:', error));
```

Important Notes:
---------------
-   The import process will **upsert** data: if an item with the same 'id' already exists in the database, it will be updated; otherwise, a new item will be created.
-   The server directly accesses 'unified_data.json'. Any changes to this file must be saved before triggering the import for the changes to take effect.
-   This endpoint is currently set to `Public` access. In a production environment, you might want to secure it (e.g., with authentication) to prevent unauthorized data imports.
